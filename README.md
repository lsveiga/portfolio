## Competências demonstradas

- **Produto e arquitetura:** partir de um problema de negócio, definir o que o sistema *não* faz e desenhar o modelo de dados antes da tela.
- **Back-end e banco de dados:** PHP + MySQL, PostgreSQL com Row Level Security, Supabase, migrations versionadas com testes.
- **IA aplicada:** agentes com prompts controlados, regras anti-alucinação, pipelines em n8n e API da Anthropic.
- **Front-end:** HTML/CSS/JS sem build, PWA offline-first, Next.js/React, landing pages de alta fidelidade visual.
- **Operação:** deploy via Git e FTP, servidores próprios, documentação para quem opera o sistema.
- **Segurança e qualidade:** isolamento entre clientes (multi-tenant), auditoria de permissões, suíte de testes no banco.
